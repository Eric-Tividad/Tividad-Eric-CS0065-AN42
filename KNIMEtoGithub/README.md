# Asynchronous Activity 2 - Uploading a KNIME Project to GitHub

This repository contains the required output for Asynchronous Activity 2. The project uses KNIME to create a model for predicting student risk status from their academic performance data.

## Algorithms used:
- Decision Tree
- Logistic Regression
- Random Forest

## Significant Files:
- Activity 2_StudentWarningTool.knwf - exported KNIME model workflow
- student_performance_knime.csv - dataset used by the workflow

## To Run:
1. Import the `.knwf` file into KNIME Analytics Platform.
2. Configure the CSV Reader and select the included dataset.
3. Execute all nodes.
4. Open the Scorer nodes to review the evaluation results.
